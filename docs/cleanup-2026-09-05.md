# Production cleanup — September 5, 2026

## Agent Gateway changes

- `/readiness` now filters by project, priority, and status using a GET form.
  P2 and completed counts are visible. Filtered projects expand automatically,
  query values are allowlisted, empty results are explicit, and the global totals
  remain visible. Rendering stays server-side under the existing script-free CSP.
- The readiness HTML is no longer emitted as a static asset that could shadow the
  server's query processing on Vercel. Dist mode delegates this route too.
- The GitHub release check uses the workflow's existing token only on the fixed
  GitHub API endpoint, refuses redirects, and has a ten-second timeout. Rate
  limits, unavailable responses, and malformed metadata fail with their own
  diagnostic and cannot generate a fictitious release mismatch against undefined.

Issue #19's original August 22 monitoring failure reported GitHub HTTP 403, followed
by a mismatch against an undefined tag. The five latest monitoring runs inspected
on September 5 passed, including run 33934474125. The historic issue is left open;
this change does not claim a new production rollout or incident-owner signoff.
