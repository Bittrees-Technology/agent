# Ecosystem rollout ownership

The standalone service and project-by-project rollout plan are owned by
[Bittrees-Technology/mcp](https://github.com/Bittrees-Technology/mcp/blob/main/docs/ecosystem-rollout-plan.md).
Agent owns onboarding/discovery, contribution review and migration compatibility.
See [the Agent migration contract](ecosystem-integration.md) for local routes,
selection handoff, catalog snapshots and authorization boundaries.

MCP production activation, database/secrets, domain verification, integration
adapters, automation and rules are independently managed in that repository.

Keep all nine products in the migration contract’s [exclusion list](ecosystem-integration.md#excluded-products) out of discovery and active plans until explicit owner reapproval.
